# ZTPAI2025-26
**Technology Stack Summary:**
This stack uses Next.js as a full-stack framework, handling both the frontend (React) and the backend (API logic), connected to a PostgreSQL database.

- Frontend (Next.js: A production-grade React framework. It provides a robust foundation with built-in routing, image optimization, and flexible data-fetching methods.

- Backend (Next.js): The backend logic is co-located with the frontend using serverless functions. API Routes are used for creating REST/GraphQL endpoints, while Server Actions simplify data mutations directly from React components, reducing boilerplate.

- Database (PostgreSQL): A powerful and reliable open-source relational database. It's chosen for its scalability, support for complex queries, and robust features like JSONB support, making it ideal for applications that need to manage complex, structured data.
